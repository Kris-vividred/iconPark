# iconPark

iconmonstr.com 홈페이지 구조를 참고해 만든 아이콘 라이브러리 홈페이지입니다. 브랜드(monoline)와 아이콘은 모두 새로 그린 것입니다.

- 단일 파일: `index.html` (빌드 없음, 외부 의존은 Google Fonts뿐)
- 아이콘 39종 × 라인/채움 = 78개, 6개 컬렉션
- 검색 자동완성, 컬렉션·스타일 필터, 페이지네이션
- 상세 창: SVG/PNG 전환, 색상·PNG 크기 선택, SVG·Base64 코드 복사, 즐겨찾기(localStorage)
- 라이트/다크 모드

GitHub Pages로 배포하려면 Settings → Pages에서 `main` 브랜치 루트를 선택하세요.
